Remarks

This is a CLI wrapper with fluent API that allows to modify the following arguments:

  • --config-path via ConfigPath
  • --package-name via PackageName
  • --package-namespace via PackageNamespace
  • --package-version via PackageVersion
  • --repository via Repository
  • --tcli-directory via DataDirectory
  • --token via Token
